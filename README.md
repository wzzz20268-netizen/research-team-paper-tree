# 研究组论文树 · Research Team Paper Tree

**中文**

从一篇论文出发，追踪每位通讯作者在论文发表时所属的研究组。每个研究组各有一棵论文树，按研究方向分支，分支内按时间排序，涵盖直接相关的成果和相似方向的论文。同一研究的预印本与正式发表版合为一条，并保留各版本链接。每个研究组还附有可核查的简介，包括代表性成果、合作与公开资助。

使用时，提供论文文件、标题、DOI 或链接即可。

**English**

Start with a single paper and trace each corresponding author to their research group at the time of publication. The skill builds a separate paper tree for each group, with branches for the main research direction and related lines of work. Papers are listed chronologically within each branch. Preprint and published versions are grouped under one entry, with links to both. Each group also gets a source-backed profile covering representative publications, collaborations, and publicly documented funding.

Provide a paper file, title, DOI, or link to get started.
